# Changelog

## TeamPulse portfolio adaptation

### Added
- Streamlit dashboard with date/department filters, employee search, workforce KPIs, charts, a summary table and CSV exports.
- Local demo sign-in configured through Streamlit secrets or environment variables.
- `secrets.toml.example` and Git ignore protection for local credentials.
- A rewritten README covering installation, login, pipeline execution, testing and dataset limitations.
- A consistent light UI theme with readable KPI cards, improved chart colors, softer page spacing and a cleaner sidebar.

### Changed
- Project identity and Python distribution metadata to TeamPulse — Workforce Insights.
- Internal package/version lookup labels to match the new project name.
- License notice retains upstream copyright and adds a notice for customizations.
